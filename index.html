Enterprise Architecture

Engineered for Uncompromising Security

Combining high-speed LuaJIT coroutines with a compiled Go control plane and modern Cyber-SOC dashboard.

🧠

Semantic AST Inspection

Parses requests into Abstract Syntax Trees instead of brittle regex patterns, defeating evasion techniques like comment injection, hex encodings, and nested payloads.

🤖

Silent Anti-Bot PoW

Mitigate scrapers, credential stuffers, and brute-force scanners using seamless cryptographic Proof-of-Work client challenges without annoying CAPTCHAs.

🔒

100% Data Sovereignty

Zero cloud dependencies. Your logs, telemetry metrics, customer traffic, and private SSL keys stay entirely inside your own hardware boundary.

⚡

Direct Kernel IP Preservation

Utilizes host networking mode to eliminate Docker NAT bridge overhead, preserving true client IPs for accurate geo-blocking and rate limiting.

📜

Auto Let's Encrypt SSL

Automated zero-downtime ACME client issues and renews free TLS certificates automatically, or upload custom enterprise wildcard certificates.

🛡️

CIS Benchmark Hardened

Every container executes as non-root (UID 1000), drops ALL Linux capabilities, and operates on an immutable read-only root filesystem.

Up and Running in 2 Minutes

Deploy via 1-line script or standard Docker Compose stack.
